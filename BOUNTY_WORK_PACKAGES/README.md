# Bounty Work Packages

This is the local archive root for AA Bounties Dashboard work packages.

The deployed dashboard cannot write here until the operator grants browser permission.
In the dashboard, press `Connect Track Folder` and select this folder:

C:\Users\andre\APPS\AA-STUDIO\BOUNTY_WORK_PACKAGES

Each challenge/project will be created as:

bounty-<id>/
  challenge/
  feasibility/
  solution/
  ops/

Supabase stores package metadata, artifact records, and agent events. This folder keeps the local working copy of the challenge, solution, patch, evidence, and submission packet.
